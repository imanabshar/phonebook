# Phonebook
A full-stack contact management application built with React, Express, and MongoDB for storing and managing contacts through a RESTful API.

## Project Overview
- Built a RESTful API with Express and MongoDB/Mongoose for persistent contact management, including regex-checked phone validation and minimum-length name checks.
- Added centralized error-handling middleware for cast/validation errors, plus a custom Morgan token to log request bodies for easier debugging.
- Deployed the React frontend and Express backend as a single application on Render, with the backend serving the production build.
